### About

Full-stack developer building **SaaS platforms**, admin dashboards, **AI-integrated web apps**, and conversion-focused websites.

I take products end-to-end: architecture, database design, interface, deployment, and performance. Then I leave a codebase that is typed, documented, and easy to hand off.
